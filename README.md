## 📌 Project Overview

This project automates the **entire customer communication workflow**:

- Generate personalized payment reminder letters  
- Convert them into individual PDF files  
- Map PDFs to customer records  
- Send emails automatically with attachments  

👉 Built using **Excel VBA**, integrated with Word & Outlook.

---

## 🚀 Key Features

- 📄 **Dynamic Letter Generation (Word via VBA)**
- 📑 **Auto PDF Creation (One per Customer)**
- 🔗 **PDF Path Mapping in Excel**
- 📧 **Automated Email Sending via Outlook**
- 👤 **Personalized Emails (Name + Amount)**
- 📊 **Status Tracking (Sent / Failed / Missing)**

---

## 🛠️ Tech Stack

- Microsoft Excel (VBA)
- Microsoft Word (Automation)
- Microsoft Outlook (Email Automation)
- File System Handling (PDF Storage)

---

## 📂 Workflow

1. 📊 **Input Data in Excel**
   - Customer Name  
   - Email ID  
   - Pending Amount  
   - Due Date  

2. 📝 **Generate Letters**
   - VBA creates Word document dynamically  
   - Each customer → separate page  

3. 📄 **Convert to PDFs**
   - Each page saved as individual PDF  
   - Named using customer name  

4. 🔗 **Map PDF Paths**
   - File paths stored in Excel (Column F)  

5. 📧 **Send Emails**
   - Outlook automation  
   - Attach respective PDF  
   - Personalized subject & body
